s_agent

A fast, hands-on coding agent for your terminal. It reads your codebase, edits files, runs commands and tests, drives a real browser, controls desktop apps, and verifies its own work.

Features

Everything a coding agent needs — nothing it doesn't.

⚡Fast core

Pure-stdlib core, zero required dependencies, ~20 MB RAM. Independent tool batches run in parallel.

📴Offline-ready

Built-in local engine works with no API key. Plug in OpenAI, Gemini, DeepSeek, Ollama & more when you want.

🌐Real browser

Playwright, Firefox-first: open · text · click · fill · screenshot on live pages.

🖥️Desktop control

PyAutoGUI with FAILSAFE: screenshot · click · type · hotkey · locate.

🌍Multilingual

English, Arabic, French, Spanish — understands tasks and replies in your language.

🛡️Safe by default

Blocked destructive targets, confirmation prompts, /diff review before you trust it.

Install

Two minutes, Windows / macOS / Linux.

git clone https://github.com/salim-studio/s_agent.git
cd s_agent
pip install -e ".[full]"
python -m playwright install firefox
python -m s_agent doctor
python -m s_agent lang ar   # or en · fr · es

Usage

Interactive, one-shot, or swarm.

python -m s_agent
python -m s_agent run "find the main function" --yes
python -m s_agent swarm "review this project" --yes
python -m s_agent browser open --url https://example.com
python -m s_agent desktop screenshot

CommandWhat it does
run "task"Run a single task, report with evidence
swarm "goal"Parallel agents, merged result
browser …Real-browser automation
desktop …Desktop automation
lang · login · doctorLanguage, providers, health check
